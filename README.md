# android-course-projects

Android 开发课程项目仓库。

## 目录结构

- `projects/`：按课程实验或作业分项目存放。

## 当前项目

- `projects/01-register-page/`：注册界面实战练习，包含 XML 布局、表单校验和提交提示。
- `projects/02-headline/`：仿今日头条推荐列表，包含标题栏、频道栏、RecyclerView 多类型列表和图片资源展示。
- `projects/03-mall-list/`：购物商场列表，基于 RecyclerView 实现商品图片、名称和简介的竖直列表展示。

## Android Studio 打开方式

- 可以直接打开仓库根目录 `MyApplication/`。
- 根目录已经映射为多模块工程。
- `app` 对应 `projects/01-register-page/app`
- `headlineApp` 对应 `projects/02-headline/app`
- `mallApp` 对应 `projects/03-mall-list/app`

## 后续建议

- 新项目继续按 `projects/04-xxx`、`projects/05-xxx` 这样的方式新增。
- 每个项目目录保留自己的 `README.md`，方便记录作业要求和运行方式。
